## lec 6

Let the solver also output a **proof log**, which is generated by specific algorithm, also considering the readability and checkability simutaneouly. The proof log is written in format **PBC**, inferred by **cutting planes**, **RUP** and **strengthening**.

Pseudo-Boolean constraint is a kind of constraint written in format like inequalities in linear programming.

cutting planes are rules to operate the PBCs to get stronger conditions and lead to conflict.

RUP is reverse unit propagation, which assume a new constraint C to be false, and do unit propagation. If leads to conflict, then we get new constraint C.

strengthening means adding new constraint C, but not logically implied from the original constraints. But adding C will not change the satisfibility of the original problem.

---

The proof checker here we used is VeriPB, which is similar to lean.
