### 1.1 Bits

### 1.2 Process a C program 

**High-level language** is human readable, while **low-level language** is machine readable.

For a source C program `hello.c`, which is a **text file**, it will be complied into a **binary file**, which is machine readable. In this process, there are processor, complier, assembler and linker. 

Complier output **assembly language**, which is same for any complier, i.e. a C complier and a Fortran complier will output the same assembly language. Assembly language is still in text form, while at the next step, the assembler will turn the text file into binary file.
